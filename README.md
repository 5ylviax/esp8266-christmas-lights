# esp8266-christmas-lights
automatically turns on and off christmas lights

## How to run
1. In Arduino IDE, open **File → Preferences** and add this URL to **Additional Boards Manager URLs**:
   `https://arduino.esp8266.com/stable/package_esp8266com_index.json`
2. Open **Boards Manager**, search for `esp8266`, and install **esp8266 by ESP8266 Community**.
3. Select **LOLIN(WEMOS) D1 mini Pro** as the board and choose its COM port (mine is `COM7`).
4. Open `christmaslights/christmaslights.ino` and click **Upload**.
